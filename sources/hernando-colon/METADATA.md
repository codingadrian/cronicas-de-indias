# Historia del Almirante

**En pausa por decisión del proyecto**, junto con las *Cartas de relación* de Cortés. Motivo: la fuente disponible (Internet Archive, edición de Luis Arranz) mezcla notas editoriales modernas dentro de los capítulos por un problema de orden en el volcado OCR — no se pudo separar de forma confiable el texto de 1571 del aparato editorial moderno. Se retoma más adelante, ya sea limpiando esto a mano o buscando una edición distinta.

Nota positiva para cuando se retome: el texto incluye completa, entre los capítulos LXI y LXIII de Colón, la "Relación acerca de las antigüedades de los indios" de fray Ramón Pané —un documento de autoría propia que vale la pena tratar como fuente independiente.
